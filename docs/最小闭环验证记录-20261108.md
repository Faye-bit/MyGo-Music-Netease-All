# 最小闭环验证记录

日期：2026-11-08。

## 环境与范围

- 本机 MyGo Music：0.1.21。
- 原插件：网易云音乐 0.1.6；保留原安装与登录状态。
- 验证插件：`netease-validation` 0.0.1，独立会话、只读业务入口。
- 源码：[validation-plugin](../validation-plugin/README.md)。安装包：`validation-plugin-0.0.1.zip`。
- 本轮目标：新插件独立扫码登录、歌单读取、选择有权限歌曲验证完整播放；不修改云端歌单。

## 本地检查

语法检查通过，4 项模拟测试通过：

1. 未登录首页不请求网络，未导出喜欢及歌单写接口。
2. 退出清除账号与诊断数据。
3. 取流记录不含 Cookie、音源地址或歌曲标识。
4. 试听返回被拒绝，不能记作完整音源成功。

这些结果仅验证代码逻辑，不代表网易在线接口已通过。

## 结论与后续

客户端接口路线的最小闭环已获得真实账号证据，可以据此推进第一阶段正式实现。没有修改云端歌单或喜欢状态，测试结束时播放器暂停在约 2:45，当前来源仍为验证插件，原插件未卸载。

发现宿主 0.1.21 首页不展示插件提供的 `description`，因此目前首页中的最近取流说明不可见；歌单验证子页面的描述正常显示。后续将音源诊断放到独立子页面，再开展精确音质验证，不能因为本轮播放成功就填写具体码率或 Hi-Res 已通过。

第一阶段后续重点：非空喜欢列表样本、完整分页及大歌单、登录失效/取消的实机行为、其他原有功能回归。首页推荐与五档音质仍按开发 Plan 分阶段验证。
