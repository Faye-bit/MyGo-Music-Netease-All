# 网易云音乐 All · 第三阶段插件侧 0.3.1

可独立安装的 MyGo Music 网易云音乐插件。插件 ID 固定为 `netease-all`，与旧插件 `netease`、只读验证版 `netease-validation` 分开存储。不依赖旧插件、Node、API 服务或外部播放器。

支持环境下限设为 MyGo Music **0.1.22**，以本机当前版本与核对过的宿主协议为支持基线；不宣称这是所有 API 首次可用的版本。运行时代码为一个无导入的 `index.js`，另附四张本地主题封面。使用本地文件夹安装时请选择项目根目录，以同时包含入口和 `assets/`。

## 安装及回退

1. 在 MyGo Music 的「设置 → 插件 → +」中从本机 Zip 安装 `netease-all-0.3.1.zip`。
2. 选择「网易云音乐 All」，从账号入口扫码。会话保存在宿主插件存储中，重启后恢复；普通存储不等于系统钥匙串。
3. 点击底部账号进入「账号与同步」，可读取自建、收藏和喜欢列表。侧栏使用播放器刷新按钮重新加载；喜欢列表从第一页刷新时重新读取云端。
4. 保留旧插件，独立验收时停用它。新插件不迁移旧 Cookie，也不改写旧来源的收藏、播放队列或缓存。
5. 回退时切回旧插件即可。退出新插件只清除新插件的会话、业务缓存与脱敏摘要，不调用网易全局退出，不删除其他设备登录或宿主音频缓存。

## 登录取消

本版包含待扫码、待确认、校验账号、成功、过期、超时和取消状态。退出、开始新一轮登录、成功切换账号及明确取消都会使旧请求结果失效。

**宿主 0.1.22 的扫码框「取消」只隐藏窗口，不会通知插件。** 要停止轮询，关闭窗口后点击底部账号进入「账号与同步 → 取消扫码登录」。如果该页面或操作结果页被播放器缓存，请使用播放器刷新按钮重新执行。此操作不退出当前已登录账号。二维码最长等待 3 分钟；未收到有效 Cookie 并通过账号校验前不会保存新会话。

## 歌单和写入

- 分页读取自建与收藏歌单，保持服务端顺序及 ID；超过 2000 个继续分页，重复页、无进展页或超过 20000 项时明确失败。
- 歌单用完整 `trackIds` 按每批 400 首补详情，最多两个并发请求，保持原始顺序；删除或无详情歌曲保留不可用占位，不挤占后续歌曲的位置。
- 单页最多加载 **10000 首**；超过上限，或服务端未返回全部 ID，描述显示「未完整同步：已加载 X/Y 首」及原因。大歌单在真实宿主上的性能仍待验收；超时则报错，不声称同步完整。
- 「账号与同步」只确认目录和喜欢 ID 的读取，不将尚未打开的所有歌单标成曲目同步完成。刷新同步仅为读取，没有后台自动合并或自动批量写回。
- 保留喜欢/取消喜欢与歌单增删曲目。写请求串行执行；成功后重新读取云端核对。网络错误、超时、重复或结果不符时不自动重发写请求。超时可能已在云端生效，先刷新核对再手动操作。
- 「我喜欢的音乐」固定歌单标为 `fixed`，通过歌曲的喜欢按钮修改；不新增创建、重命名或删除歌单、评论写入或播客订阅写入。

搜索、专辑、歌手、发现、日推、雷达、个性化歌单、榜单、三种私人漫游、歌词、评论读取和播客入口保留。首页个性化与日推展示已在第二阶段实现；本版兼容宿主 standard/high/lossless 三档协议；候选五档请求映射已实现，不宣称原生五档或 Hi-Res 实机验收通过。

## 首页推荐与刷新

首页不显示账号分区；侧栏加入「每日推荐」，移除重复的「我喜欢的音乐」和「账号与同步」。喜欢歌单保留在下方「我的歌单」，同步页仍可从底部账号进入。卡片尺寸和列数由 MyGo 主程序控制，当前插件协议没有布局尺寸选项。

- 登录后，首页首个分区提供网易云日推歌曲，使用 MyGo 原生日推大卡片、播放按钮、歌曲封面堆叠和悬停唱片效果。点击大卡片进入宿主同一分区的详情页，播放顺序与首页一致。
- 下方歌单使用登录后的个性化推荐接口。未登录只显示明确标注的普通推荐与登录提示；雷达和日推详情需要登录。
- 雷达封面取对应歌单；排行榜和三种私人漫游使用随包附带的独立主题封面。主题图不代表队列预览。首页和漫游列表不提前请求漫游歌曲，不因装饰封面跳过首批内容。固定雷达 ID 是否随真实账号变化仍待双账号验证。
- 日推在内存中按会话、账号和中国日期缓存；跨日重新请求，以服务端返回为准，不保证午夜就更换曲目。推荐歌单和雷达封面缓存 5 分钟。重启、退出、重新登录或切换账号后重新读取。
- 首页不再显示「刷新首页推荐」卡片。需要强制重取时，进入「账号与同步 → 刷新首页推荐」，再使用播放器刷新操作更新首页大卡片。操作结果页若被宿主缓存，可刷新该页再次执行。宿主自己的页面缓存不能由插件直接清除，单点宿主刷新可能仍复用当天日推缓存。
- 日推、推荐歌单和雷达封面分别加载，普通网络/内容错误只影响对应分区；鉴权过期仍由统一会话层提示重登。失败结果不长期缓存。首页推荐任务去重，最多两个同时进行，完整推荐歌曲详情直接复用，缺失详情才补取。
- 漫游每模式记录最近 500 首已返回曲目；连续三批只含重复歌曲或遇到空批时返回空列表停止追加。并发追加串行执行。该模式停止后，本次会话不继续自动轮询；重新登录/重启可重新开始。不会通过随机本地歌曲补齐推荐。

日推详情使用「每日推荐 / 每日歌曲推荐 / 根据你的音乐口味生成」的文案层次；侧栏日推页补充中国日期、星期与歌曲数，复用首页当天歌曲。首页大卡片打开的日期封面、背景虚化和文字颜色仍由宿主决定，插件无法调整，也不宣称完成原版视觉还原。

## 隐私与诊断

「播放诊断」只存储最近成功取流的请求偏好、请求/实际/服务端档位、宿主三档分类、格式、码率、大小、有效秒数和时间；采样率/位深仅在服务端实际提供正数时保存。不存 Cookie、音源 URL、歌曲 ID 或原始响应。完整音源取流成功与实际播放验收分开记录；拒绝试听和不支持的音源域名。

## 第三阶段音质行为

- 在 MyGo 设置中选择标准、高音质、无损，分别请求 `standard`、`exhigh`、`lossless`。无损不暗中请求 Hi-Res。候选 `higher`、`exhigh`、`hires` 也有明确映射，但当前宿主没有对应独立设置；没有新增文本音质偏好。
- 只接受有完整权限、非试听、有效网易音源域名及支持格式的地址。缺格式、显式过期或无 URL 均明确失败。服务端返回完整低档音源时按实际值分类；不因权限、风控、限流、超时或空 URL 逐档重试。本版取消旧版对 460 风控拒绝的自动重试。
- 无损/Hi-Res 标签需与 FLAC 格式一致；矛盾或缺失档位记为 `unknown`。FLAC 只归宿主无损，不凭扩展名、请求档位、码率或会员身份推断 Hi-Res。有损缺档位时仅按已知码率归类，信息不足保守归标准，避免宿主按所请求无损缓存。实际解码仍需播放器验证。
- 同曲同有效请求档位的进行中请求合并；完成后不缓存地址，下次调用重新取流。退出/换账号后旧结果不能返回或写摘要。播放失败后可手动重试；插件不能接收宿主的下载失败回调，也不能主动刷新已被宿主使用的 URL。
- 宿主设置在下一次加载歌曲时参与选择，可能命中宿主缓存或预加载。现有缓存允许复用更高三档音质，同一插件 ID 的缓存也不按账号隔离；退出插件不会删除音频缓存。摘要只代表最近成功取流，不能证明当前缓存播放档位或重新授权成功。
- **第三阶段插件侧完成，完整五档待宿主支持。** 真实五档样本、解码、重启及缓存矩阵尚待实机验证。依赖与待测清单见 `docs/验收记录-阶段3.md`（源码仓库）。
